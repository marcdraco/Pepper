# Pepper
Single FET breakout board for JLI2555 microphone capsule

![image](https://github.com/user-attachments/assets/90bfa8d9-dbe2-458e-9bb7-9c849563a1bb)
![image](https://github.com/user-attachments/assets/a6c47a3e-3ec5-41ba-b35f-c467adb85448)

Carrier lugs can be removed as necessary. The JFET is intended to go INSIDE the capsule mount to give extra RFI protection.
